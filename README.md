# Math League Practice

Original 5th-grade practice web app in **mathleague.org** style (Number Sense, Sprint, Target).

**Contest target:** Saturday, November 14, 2026

Not affiliated with mathleague.org. Questions are original — similar skills and scoring only.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
